# SunNight 기획 보강안 v0.1

작성일: 2026-10-15

상태: **대화에서 제안한 미확정 초안**. 기존 기획을 대체하는 확정 사양이나 구현 완료 내역이 아니다.

## 1. 핵심 경험

> 낮에는 자원을 찾아 이동하고, 밤에는 직접 키운 이동식 거점을 지키며, 위험한 지역을 돌파하는 생존 디펜스 게임.

기능 추가보다 채집·이동·건설·방어·공장 공략이 서로 다음 행동의 이유가 되도록 연결한다.

- 채집: 오늘 밤 방어와 다음 이동 준비.
- 건설: 제한된 자원으로 방어 방식 선택.
- 이동: 더 좋은 자원을 얻기 위해 안전을 포기하는 선택.
- 공장: 새로운 지역으로 나아가는 목표와 성장 보상.

주변의 유한 자원으로 이동 동기를 만든다. 자원을 소진한 상태에서 진행이 영구적으로 막히지 않을 최소 복구 수단은 별도로 정한다.

## 2. 거점 이동 규칙 제안

기존 기획의 운반 경험을 살리는 방향으로 먼저 검증한다.

| 항목 | 초기 검증안 | 목적 |
|---|---|---|
| 운반 대상 | 거점과 부착 시설을 함께 운반 | 이전 성장을 보존 |
| 운반 중 행동 | 이동·기본 공격 가능, 포탑 공격 중지 | 위험과 대응 수단 제공 |
| 운반 비용 | 이동속도 감소부터 적용 | 별도 게이지 없이 부담 전달 |
| 재배치 | 유효 공간에서 짧은 설치 시간 필요 | 전투 중 즉시 요새화 제한 |
| 운반 중 사망 | 초기 테스트에서는 복구 가능한 손실 | 이동 시도 자체를 억제하지 않도록 검증 |

기존의 운반 중 사망 시 게임 오버 규칙을 확정 변경한 것은 아니다. 운반의 재미를 먼저 검증한 뒤 실패 강도를 결정한다. 속도 감소량·설치 시간·손실량은 미정이다.

## 3. 하루의 플레이 흐름

1. 아침에 거점 내구도와 식량을 확인한다.
2. 가까운 고철 지대에서 수리 재료를 구할지, 먼 공장 주변에서 새 포탑 재료를 구할지 선택한다.
3. 해가 지기 전에 돌아와 수리와 포탑 제작에 자원을 배분한다.
4. 밤의 공격을 막는다.
5. 주변 자원 잔량과 방어 결과를 보고 다음 날 이동 여부를 결정한다.

수리와 강화가 항상 모두 가능하면 선택의 의미가 약해진다. 반대로 필수 생존 비용만으로 모든 자원이 소모되면 전략을 만들 수 없다. 이 사이의 자원 여유를 플레이 테스트로 조정한다.

## 4. 시스템별 작성 기준

각 시스템을 역할·기본 규칙·상태 변화·예외·실패 복구·표시 방식으로 작성한다.

허기 예시:

| 항목 | 확정해야 할 질문 |
|---|---|
| 역할 | 탐험 시간을 제한하고 식량을 챙기게 하는가? |
| 기본 규칙 | 언제 감소하며 음식별 회복량은 얼마인가? |
| 상태 변화 | 부족하거나 바닥났을 때 어떤 불이익이 있는가? |
| 예외 | 메뉴·대화·보스 연출 중에도 감소하는가? |
| 실패 복구 | 식량이 없는 상태에서 회복할 방법은 무엇인가? |
| 표시 | 위험을 사전에 어떻게 알리는가? |

허기와 스태미나는 서로 다른 선택을 만들 때 함께 사용한다. 역할이 겹치면 첫 검증에서는 하나만 사용하는 안을 고려한다.

## 5. 우선 완성할 범위

탐험 → 거점 이동 → 방어 → 성장 → 폭스턴으로 이어지는 완결된 한 구간을 먼저 설계한다.

검증 조건:

- 모은 자원과 만든 시설이 다음 구간까지 이어진다.
- 방어에서 겪은 문제가 다음 채집·제작 선택을 바꾼다.
- 보스전 전에 준비한 결과가 전투에 영향을 준다.

첫 공장의 경험을 완성한 뒤 다음 공장이 요구할 새로운 판단을 설계한다. 공장 수·적 종류·챕터 확대는 이후 단계로 둔다.

## 6. 밸런스 설계 기준

개별 수치를 확정하기 전에 다음 목표를 정한다.

- 기본 적을 처치하는 데 필요한 공격 횟수.
- 적을 방치했을 때 거점이 버티는 시간.
- 첫날 수집량으로 만들 수 있는 포탑 수.
- 충분히 준비한 밤과 준비가 부족한 밤의 난이도 차이.

일반 기획과 쇼케이스의 수치는 적용 범위를 구분한 기준표로 통합하고 변경 이유를 남긴다. 현재 구현 수치를 확정 기획값으로 자동 채택하지 않는다.

## 7. 다음 확정 항목과 테스트 목표

우선 확정할 항목은 핵심 경험, 하루 흐름, 거점 운반, 사망·복구, 첫 공장과 폭스턴까지의 진행이다. 확장 아이디어는 별도로 보관한다.

첫 테스트의 핵심 질문:

> 플레이어가 스스로 “내일은 저쪽으로 거점을 옮겨서, 이 재료로 방어를 보강해야겠다”라고 판단하는가?

이 판단이 생기는지 관찰하고, 이동하지 않는 이유·자원 선택의 이유·실패 후 복구 가능성을 기록한다. 아직 플레이 테스트를 수행한 결과는 없다.
