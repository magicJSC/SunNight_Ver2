# 첫 필드 밸런스 검증 — 2026-10-28

상태: **부분 실행 검증 및 1차 조정. 튜토리얼부터 폭스턴 처치까지의 연속 플레이 검증은 아직 완료하지 않았다.** Unity 6000.5.10f1, `feature/level-design`의 작업 트리 기준이다.

## 검증 방법과 범위

- 새 게임에서 이동 입력 처리와 Rigidbody 충돌을 유지하며 시작 집 → 북쪽 출입구 → 제작대 주변 → 퍼즐 앞까지 이동했다. 기존 쓰레기 더미에서 실제 조사로 고철 20개가 지급되는 것을 확인했다. 이동 중 자원 지급·순간이동·강제 처치는 하지 않았다.
- 이후 전투 비교는 **시설·시작 위치를 설정하는 별도 시험**이다. 실제 몬스터 AI, 이동, 타깃 선택, 공격 애니메이션, 피격·파괴를 사용했다. 플레이어는 근접 적을 피하는 이동만 하고 공격하지 않았다. 정상 채집·제작을 거친 플레이 기록이 아니다.
- 연구 적용, 보급 총량, 허기, 공장 씬 전환은 별도 회귀검사다. 강제 설정한 데이터와 실제 획득 데이터를 구분한다.
- 배치·난수·프레임 타이밍에 민감하다. 아래 각 조건의 1회 결과로 성공률이나 일반적인 난이도를 확정하지 않는다.

## 확인한 문제와 조정

| 항목 | 확인한 기존 상태 | 반영 |
|---|---|---|
| 튜토리얼 보급 | 고철 29개, 완성 대포 2개, 배트 1개 | 고철 7개(4+1+1+1), 음식 1개, 배트 1개. 대포는 제작 |
| 폐주거지 보급 중복 | 기존 상자에 고철 30·생고기 20 추가 | 새 B 지역 보급을 사용하도록 기존 추가 보상 고갈 처리 |
| 보상 재수령 | 이전 튜토리얼 채집은 신규 저장의 수령 이력과 분리 | 수령량을 탐색 상태에 저장하고 가방 미수령분 유지. 같은 지급 콜백 중복 호출 차단 |
| 적의 추가 드롭 | 기존 적은 무작위 아이템·코인 지급 | 첫 구간 세션에서는 개별 드롭을 막고 확정 지역 보급 사용 |
| 튜토리얼 방어 | 개 6·코알라 1. 최소 전력 시험 실패 | 북쪽에서 개 2마리를 순차 생성, 첫 처치 후 3초 휴식 |
| 첫밤 | 기존 데이터 개 4·코알라 2. 정수 난수로 일부 방향 누락 및 거점 위 생성 가능 | 첫 구간 런타임은 개 12·코알라 3, 북·동 12칸 접근, 3묶음, 전멸 후 10초 휴식 |
| 첫밤 이후 | 시계와 날짜가 계속 진행 | 둘째 날 05:30 고정, 반복 첫밤 생성 금지 |
| 음식 필요성 | 걷기·대기의 기본 허기 소모 없음, Shift 정지에도 추가 소모 | 활성 첫날 기본 0.05/초, 실제 달리기 이동 추가 0.10/초. 첫밤 이후 정지 |
| 무료 회복 | 대기 중 HP 자동 회복 | 첫 구간 자동 회복 제거. 허기 0이면 2 HP/초 피해. 만복 음식 소비 방지 |
| 공장 진입 | 인벤토리만 전달, 시설 소실·HP 초기화 | 시설 상대 배치·내구도·연구·인벤토리·현재 HP/허기/코인 전달 |
| 폭스턴 | 씬 HP 30, 배트 피격 인터페이스·대포 타깃 등록 누락 | 첫 구간 HP 1,100, 전투 시작 후 피격, 대포 타깃 연결 |
| 실패/완료 | 빈 무기 슬롯 재생성 예외, 마지막 생성 직후 전멸 판정 누락 가능 | 자식 개수 검사, 생성 종료 시 전멸 재확인 |

튜토리얼 공급을 줄이면서 기존 훈련 적을 그대로 두면 난이도만 급상승하므로 함께 조정했다. 첫밤의 15마리는 유지하고 접근 방향·묶음 간격을 먼저 바로잡았다. 제작비와 연구비는 변경하지 않았다.

| 수정 전 전방위 생성, 방어선 안 정지 플레이어 | 30.8초 | 플레이어 사망 | 거점 485, 대포 2·벽 4 |

| 기존 튜토리얼 개 6·코알라 1, 대포 1·벽 2 | 65.1초 | 플레이어 사망 | 거점 148, 대포 0 |

수정 전 두 정지 시험과 수정 후 회피 시험은 조작 조건도 달라졌다. 전후 결과를 생성 방향 변경만의 효과로 해석하지 않는다. U2·U3 시험은 **첫밤 이후 전력을 동일 전투에 대입한 비교**이며 실제 첫밤에 연구할 수 있다는 뜻이 아니다. 두 강화는 전투 시간이 약 14% 짧았지만 대포 손실을 완전히 막지는 못했다. HP 상향만으로 모든 배치가 안전해지지는 않는다.

## 자원 판단

구성 데이터 기준 전체 공급은 고철 71·부품 6·음식 4·약 5다. 전 지역을 정상 플레이로 모두 수령해 확인한 누적 기록은 아니다.

- 튜토리얼+A+B: 고철 25 → 대포 3·벽 6 제작비 21 → 잔고 4 → 첫밤 보상 후 8.
- 전체 연구: 고철 28·부품 6. 모든 부품이 쓰이므로 연구 비용은 유지한다.
- 전체 탐색 후 대포 4·벽 6과 모든 연구: 고철 71−20−6−28=17. 손실·수리를 차감하기 전 예산이다.
- 기본 전력 첫밤 실험에서는 벽 2개가 소실돼 재제작 2개분이 필요하다. 현행 유료 수리 기능은 미완성이므로 기획의 수리 예산을 실제 소비 검증으로 간주하지 않는다.

## 미완료 검증과 남은 구현 차이

1. 새 게임에서 실제 제작·거점 운반·D/E 경비 전투·연구 구매를 거쳐 폭스턴을 처치하는 연속 플레이와 반복 표본.
2. 현행 거점 이동은 마우스 재배치다. 기획의 운반 속도 3·설치 3초가 아직 구현되지 않아 탐색 왕복 총시간을 확정할 수 없다.
3. 폭스턴의 전체 패턴, 취약 시간, 선행전, 입장 조건은 통합 기획과 차이가 남아 있다. 피격 연결과 HP를 고친 것이 처치 시간·성공률 검증을 의미하지 않는다.
4. 유료 시설 수리, 실패 시 C3/C4/C5 선택 복귀 및 완전한 튜토리얼 퍼즐 상태 복원은 이번 검증 범위에서 완성하지 않았다.
5. 북·동 생성은 중앙 야영지 시험 배치를 기준으로 확인했다. 모든 임의 거점 위치의 장애물 회피 생성까지 보장하지 않는다.

최종 Unity 컴파일 오류 0건, 자원·허기·씬 전환·폭스턴 피격 연결 회귀검사 18개를 통과했다. [측정 원자료](level-design/v02-balance-validation.json)에 초기 이동 기록, 전투 비교, 튜토리얼 전후, 회귀검사 목록을 보관한다.

따라서 현재 결과는 첫 구간의 **측정 가능한 기준을 만든 1차 조정**이며 최종 밸런스 승인 자료가 아니다. 재현 스크립트는 `Tools/BalanceAudit.cs`, `Tools/BalanceCombatAudit.cs`, `Tools/BalanceRegression.cs`다. 실행 중 준비 상태를 덮어쓰므로 별도 Play Mode 시험에서만 실행한다.
