# 외곽 왕복 파밍 조정

같은 첫밤 이후 저장, 야영지 출발, 기본 야구방망이, 게임 내 시간 기준 실측에서 북/서/남/동 왕복은 100.6/122.2/83.7/142.7초였다. 네 곳 모두 고철 2개, 실제 추적 개체는 1/0/1/0마리였다. 특히 서·동쪽은 왕복 내내 반경 12 이내 목격도 없어 여행 보상과 조우 빈도가 부족했다.

사용자가 요청한 검증 후 조정 범위 안에서 다음을 적용한다.

- 기존 D1/D2/E1/E2 보상 상자를 각각 서/남/북/동 외곽에 이전한다. 수량·아이템·지급 ID·수집 시간·경비 해금 그룹은 그대로 둔다.
- 해당 경비 8마리를 각 상자로 함께 이전한다. 기존 외곽 순찰 4마리는 접근 중간 지점으로 옮긴다.
- 신규 자원이나 몬스터는 만들지 않는다. 첫날 A/B/C 및 강화 비용은 유지한다. 따라서 기존 수령·처치 이력도 유지된다.
- 왕복 목표 보상은 북/동 고철 6+부품 2+약 1, 서 고철 8+부품 1, 남 고철 8+부품 1+약 1이다.
- 재측정은 실제 수집·경비 전투·복귀를 포함한다. 체력 손실·물약 소비·추적 개체 수와 첫 조우까지 시간을 비교한다. 검증용 플레이어 배치는 시작 위치에 한정하며 경로 중 순간이동, 강제 피해·자원 지급은 하지 않는다.

자동 입력 실행은 2배 시간 배율에서 수행하고 게임 내 초와 실제 경과 초를 모두 남긴다. 첫밤 이후 시계·허기 정지는 기존 코드 규칙이므로 이번 시험에서 음식 소모와 다음 밤 시간 압박까지 검증했다고 주장하지 않는다.
