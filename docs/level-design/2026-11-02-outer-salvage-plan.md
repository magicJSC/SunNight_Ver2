# 외곽 조사 잔해 구현 계획

사용자가 승인한 방향: 각 외곽 장식 묶음에 조사 가능한 잔해, 명확한 표시, 수령 후 빈 잔해 유지. 기존 자원 총량을 고려한다.

구현 결정: 156묶음에 280 고철 조각을 배분하고 10조각마다 고철 1개를 자동 지급한다. D0_s2~s5, E0/E0_s1~s3, D1/D2/E1/E2의 고철 28개를 이쪽으로 옮긴다. 원래 부품·약·경비와 첫날 A/B/C는 유지한다. 새 아이템 슬롯 대신 저장되는 수집 조각 카운터를 사용한다. 주요 파밍 지점 주변 31묶음은 5조각, 나머지 125묶음은 1조각. 조사 1초, 이동/피격 취소, 지급 시 인벤토리가 차면 해당 조사는 소비하지 않는다. 고철 수령 이전 조각도 저장한다.

대안: 모든 묶음에 고철 1개 지급은 총량을 과도하게 늘리고, 확률적 빈 보상은 모든 묶음에서 파밍하려는 요청에 맞지 않는다. 따라서 작은 확정 보상을 합치는 방식을 선택했다. 기존 외곽 왕복 보상 속도는 달라지므로 이전 왕복 검증 수치를 새 버전에 그대로 적용하지 않는다.

- [x] 에디터: 기존 묶음에서 잔해 선택, 좌표·경로 저장, 재생성 시 갱신.
