# 외곽 밀도 보강

사용자 선택: 풍경 보강 + 기존 자원·몬스터 분산. 자유 탐색을 유지한다.

- 북쪽 숲·야영 흔적, 서쪽 수풀·폐가구, 남쪽 야적장, 동쪽 산업 잔해를 독립된 무리로 배치한다. 도로로 연결하지 않는다.
- 기존 첫날 A/B/C 자원과 야영지 안전거리는 유지한다. D0/E0의 잔해 8곳과 후반 순찰 4곳을 외곽으로 옮긴다. 총량·ID·보상·연구비는 바꾸지 않는다.
- `OuterFieldDressing` 에디터 생성기로 실제 바닥 타일 안쪽에만 장식한다. 신규 충돌체와 런타임 생성기는 추가하지 않는다.
- 기존 `FirstFieldLevelDesign` 재생성에도 외곽을 포함하고, 현재 장식 프리팹에 반영한다. 저장하지 않은 사용자 씬을 재로드하지 않는다.

실행 순서: 작업 전 프리팹·콘텐츠 백업 → 외곽 장식 및 위치 변경 → 전체/지역별 Unity 렌더 확인 → 바닥·가림·충돌·총량·ID 검사 → 결과 기록.

검증에서는 지형 밖 배치, 보상 가림, 야영지/튜토리얼 침범, 자원 중복 지급, 기존 저장 ID 변경을 확인한다. 초반 준비 시간은 A/B/C 배치 불변으로 보호하며 이번 작업에서 전체 첫날을 재플레이했다고 주장하지 않는다.
