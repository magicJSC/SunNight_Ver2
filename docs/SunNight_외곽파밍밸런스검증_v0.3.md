# 외곽 왕복 파밍 밸런스 검증 v0.3

2026-11-02 · Unity 6000.5.10f1 · `feature/level-design`

## 결론과 반영

조정 전에는 왕복 84~143초를 써서 고철 2개만 얻었고, 서·동쪽은 몬스터를 가까이서 만나는 일도 없었다. 먼 외곽을 방문할 보상이 부족했다.

**기존 경비 보상 상자 D1/D2/E1/E2를 서/남/북/동 외곽으로 옮기고 담당 경비 8마리를 함께 이전했다. 기존 순찰 P08/P09/P11/P12는 접근 중간으로 옮겼다.** 신규 아이템이나 몬스터를 추가하지 않았다. 자원 45곳, 몬스터 25마리, 필드 총량 고철 64·부품 6·음식 3·회복약 5를 유지했다.

첫날 A/B/C 자원, 강화 비용, 지급·처치 ID, 상자별 지급량과 경비 해금 조건은 바꾸지 않았다. 기존 파일과 최종 콘텐츠를 비교해 **위치·지역 표시명 외 직렬화 필드가 동일함**을 확인했다. 변경은 `OuterFieldDressing.Redistribute`와 실제 콘텐츠 에셋에 반영되어 재생성해도 유지된다.

## 실제 왕복 결과

시간에는 이동·실제 전투·수집·야영지 복귀가 포함된다. ‘추적’은 플레이어를 실제 타깃으로 삼은 **고유 개체 수**이며 전투 횟수나 동시 공격 수가 아니다.

| 지역 | 왕복 시간 전 → 후 | 고철 전 → 후 | 추가 획득 부품 / 약 | 실제 추적 전 → 후 | 조정 후 귀환 HP |
|---|---:|---:|---:|---:|---:|
| 북쪽 | 101 → 120초 | 2 → 6 | 2 / 1 | 1 → 3 | 83 |
| 서쪽 | 122 → 140초 | 2 → 8 | 1 / 0 | 0 → 3 | 85 |
| 남쪽 | 84 → 97초 | 2 → 8 | 1 / 1 | 1 → 3 | 85 |
| 동쪽 | 143 → 166초 | 2 → 6 | 2 / 1 | 0 → 3 | 84 |

| 지역 | 분당 고철 전 → 후 | 출발 후 첫 근접 목격 전 → 후 |
|---|---:|---:|
| 북쪽 | 1.19 → 2.99 | 37 → 20초 |
| 서쪽 | 0.98 → 3.42 | 없음 → 29초 |
| 남쪽 | 1.43 → 4.93 | 19 → 14초 |
| 동쪽 | 0.84 → 2.17 | 없음 → 40초 |

조정 후 북·서·동에서 3마리, 남쪽에서 4마리를 반경 12 이내로 목격했다. 실제 추적은 각 3마리였다. 남쪽의 기존 P05는 가까이 있었지만 이번 경로에서는 추적하지 않았다. 순찰 한 마리를 지나 목적지 경비 둘을 상대하는 흐름이며, 이들을 모두 한 번에 상대하도록 묶지 않았다.

판단: 짧은 남쪽은 초기 고철 확보, 북·동쪽은 부품 확보, 서쪽은 추가 고철 확보에 의미가 있다. 동쪽은 우회 때문에 가장 오래 걸리지만 부품 2개를 준다. 모든 루트의 분당 효율을 같게 맞추지는 않았다. 보급은 일회성이므로 남쪽의 높은 효율을 무한 반복할 수 없다. 기본 무기·무강화 상태에서도 이번 시험은 물약 사용 없이 HP 83~85로 귀환했고, 한 번의 외곽 탐색으로 대포 제작비 5개 이상과 강화 재료를 확보했다.

## 위치 변경

| 목표 | 보상 상자 위치 | 담당 경비 위치 | 중간 순찰 위치 |
|---|---|---|---|
| 북 E1 | (82, 144) | E1a (73, 134), E1b (87, 145) | P08 (70, 42) |
| 서 D1 | (-228, -99) | D1a (-210, -89), D1b (-228, -108) | P12 (-85, -81) |
| 남 D2 | (112, -253) | D2a (94, -242), D2b (116, -258) | P11 (88, -145) |
| 동 E2 | (358, 21) | E2a (341, 10), E2b (362, 24) | P09 (235, 50) |

기존 외곽 잔해 8곳의 위치는 유지한다. 새 상자 주변의 시야 확보를 포함해 장식 프리팹을 재생성했다. 최종 장식은 156무리·스프라이트 2,038개, 신규 충돌체 0개다. 지정 도로나 이동 제한을 추가하지 않았다.

## 시험 방법과 한계

- Unity Play Mode에서 각 방향 조정 전·후 1회씩, 총 **8회 왕복**했다. `Tools/OuterBalanceAudit.cs`가 실제 이동 입력, 무기 공격, 조사 상호작용을 호출했다. 거리·공식만으로 계산한 시뮬레이션은 아니다.
- 각 시험은 동일한 실제 첫밤 이후 저장 `v03-postnight-earned-postnight.json`을 읽고 **플레이어 시작 위치만 야영지 (70, -70)**로 맞췄다. HP 100, 기본 야구방망이, 무강화, 고철 4개에서 출발한다. 거점은 저장된 위치에 남겨두므로 거점 운반 시험은 아니다.
- 측정 구간에서는 순간이동, 강제 피해, 체력 보충, 자원 지급을 하지 않았다. 추적당하면 실제 공격으로 싸웠고 보상은 실제 수집했다. 모든 왕복의 오류 결과는 null, 귀환 위치는 야영지였다.
- 실행은 `timeScale=2`, 표는 **게임 내 초**다. 원자료에는 실제 경과 초도 있다. 예를 들어 조정 후 동쪽은 게임 내 166.14초, 실제 83.08초다. 종료 시 시간 배율을 복구했다.
- 알려진 목적지를 향하는 자동 입력 시험이다. 사람의 길 찾기·탐색·반응 시간을 반영한 평균은 아니다. 순찰 위상과 선택 경로에 따라 실제 조우 횟수는 달라진다.
- 기존 코드가 첫밤 완료 후 시계와 허기 소모를 정지하므로, 이번 시험은 **첫밤 이후 외곽 이동 효율**의 검증이다. 첫날 준비 시간, 다음 밤 시간 압박, 음식 소모 균형을 재검증한 결과가 아니다.

## 회귀 확인

- 바닥 위 간격 4·반경 0.7의 공간 탐색과 구간 충돌 검사에서 보급 45곳 모두 야영지와 연결됐다.
- 최종 배치의 바닥·보급 가림·경비 위치 검사 통과. Unity 컴파일 성공.
- 이전 ‘공장 진입 직전’ 저장을 실제로 복원했다. 인벤토리 동일, 보급 45곳의 수령 상태와 경비 25마리의 처치/생존 상태가 그대로였다. 위치 변경으로 이미 받은 상자가 보충되거나 처치한 경비가 재생성되지 않았다.
- 사용자 기본 저장을 덮어쓰지 않고 검증 저장은 `Logs/OuterBalance`에 작성했다. Play Mode는 종료했다.
- 콘솔은 이번 시험 시작 전에 비우지 않았으며 마지막 누적 집계는 오류 0, 경고 72였다. 입력 장치 페어링 경고 69, Missing Script 1, 기존 에디터 검색 API 폐기 예정 경고 2로 구분했다. 이 경고들을 이번 밸런스 수정으로 해결했다고 주장하지 않는다.
