# SunNight 첫 구간 구현 우선순위 v0.1

작성일: 2026-10-23

비교 기준: [통합 기획서 v0.1](SunNight_통합기획서_v0.1.md), `develop` 커밋 `9c286dc2ffd41b82e40297c10f94905883a6bcc2`.

**진행 상태·개별 시설 데이터·체크포인트 복원을 먼저 만들고, 첫밤까지 완성한 뒤 이동과 공장을 연결한다.** 현재 채집·제작·포탑·웨이브·보스 연출은 있지만, 보스 입장 시 장비와 HP를 초기화하고 시설 회수 시 내구도 정보를 잃는다. 이 상태에서는 준비한 자원과 거점을 끝까지 가져가는 기획이 성립하지 않는다.

`dev`라는 원격 브랜치는 없어 기존 개발 브랜치인 `develop`을 pull했다. `c9b1d8dc`에서 기획 PR #148이 병합된 `9c286dc2`로 갱신되었으며 이 구간의 변경은 문서뿐이다. 아래 구현 상태는 최신 체크아웃의 스크립트·씬·프리팹을 정적으로 대조한 결과다. 완료 조건은 구현 후 검증할 기준이며 Unity 실행 결과가 아니다.

## 우선순위와 완료 범위

P0~P3는 구현 순서이며, 뒤에 있는 항목도 첫 구간 완성에 필요하다. 각 기능의 최소 안내·실패 처리는 해당 기능과 함께 구현하고 P3에서 전체 흐름을 마무리한다.

| 우선순위 | 작업 | 이 단계가 끝나면 가능한 것 |
|---|---|---|
| **P0 기반** | 01~05 진행·상태 보존·저장·씬 승계·실패 판정 | 손상·소비된 상태를 저장하고 같은 상태로 재시작할 수 있다. |
| **P1 첫날** | 06~11 시간·생존·소모품·전투·튜토리얼·제작·첫밤 | 새 게임에서 직접 준비한 시설로 첫밤을 끝내고 C3에 도달한다. |
| **P2 이동과 공장** | 12~17 운반·경비·안전 설치·선행전·코어·레이저·회피 검사 | C3에서 거점을 옮겨 공장에 들어가고 폭스턴을 공략한다. |
| **P3 완주 검증** | 18~19 목표·결과·재접속·밸런스 측정 | 튜토리얼부터 C7 결과까지 처음부터 끝까지 검증한다. |
