# SunNight 기획 문서

첫 필드의 최신 배치는 **[자유 탐색 레벨디자인안 v0.3](SunNight_레벨디자인안_v0.3.md)**다. 긴 연결 길을 없애고 분산 파밍 45곳과 경비 11·순찰 14마리를 Unity에 반영했다. 자원 총량·연구 비용은 v0.2를 유지한다. 첫밤 이후 실제 탐색·연구·공장 진입과 보스 조정 결과는 **[첫밤 이후 탐색·보스 검증 v0.3](SunNight_첫밤이후탐색보스검증_v0.3.md)**을 우선한다. 변경하지 않은 규칙은 [통합 기획서 v0.1](SunNight_통합기획서_v0.1.md)을 따른다.

## 현재 기획 기준

낮에는 거점을 설치해 둔 채 탐색할 수 있다. 옮기고 싶을 때 V로 회수하면 거점이 핫바 전용 5번 칸에 들어가며, 다른 슬롯을 사용하면서 들고 다닐 수 있다. 5번을 선택하면 초록색 위치에 직접 설치할 수 있다. 21:30까지 들고 있는 거점만 플레이어 발밑이나 가장 가까운 유효 위치에 자동 설치된다. [통합 기획서 §7 거점 운반](SunNight_통합기획서_v0.1.md#7-거점-운반과-이동-중-전투)

남쪽 폐주거지의 기존 Event1 건물은 연구소로 사용한다. 건물 남쪽 정문에 접근해 입장을 선택하면 지하 연구실로 이동하며, 기존 거점 방어 이벤트는 제거했다. 주변 보급품은 연구소 조사 여부와 관계없이 수령할 수 있다. [연구소 스토리](SunNight_세부스토리_원문정리.md)

첫밤 승리 후 둘째 날 05:30부터 시계가 계속 흐른다. 이후에도 21:30에 거점 방어가 시작되며 개 12마리와 코알라 3마리가 세 차례로 나뉘어 등장한다. 첫밤 보상은 한 번만 지급한다. 아래 이전 검증 기록의 둘째 날 시계 정지는 당시 동작이다.

실행 안정성 후속 수정은 [씬 전환·저장·종료 검증 v0.3](SunNight_씬전환저장검증_v0.3.md)을 참고한다.
