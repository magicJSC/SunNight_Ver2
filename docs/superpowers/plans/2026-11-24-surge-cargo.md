# 메카모스 처치 보상 구현 계획

하역장 운송함을 F로 조사하면 남서행 운송 기록, 동부 피난 거점 약도, 손상된 절연 장치를 한 번에 얻는다. 서지 진행안의 운송함 단계까지 구현한다.

- [x] ExplorationState에 개봉 여부와 퀘스트 장치 보유를 저장한다. 처치 전 개봉, 반복 지급, 옛 저장의 기본값을 검사한다.
- [x] MecamossReceivingHall의 기존 화물에 처치 후 조사 영역을 켠다. 미수령 재입장과 빈 상자 재입장을 검사한다.
- [x] FieldHUD에 운송 기록과 동부 수색 범위가 표시된 약도를 추가한다. 개봉 전후 미션, 페이지 이동, 다른 지도 표식을 검사한다.
